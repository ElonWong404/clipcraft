## Agent skills

### Issue tracker

GitHub Issues — https://github.com/ElonWong404/clipcraft/issues. External PRs are a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs
