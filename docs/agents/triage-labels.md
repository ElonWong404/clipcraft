# Triage Labels

| Role | Label | Purpose |
|------|-------|---------|
| Evaluation | `needs-triage` | Maintainer needs to evaluate |
| Waiting | `needs-info` | Waiting on reporter |
| Agent-ready | `ready-for-agent` | Fully specified, AFK-ready |
| Human-ready | `ready-for-human` | Needs human implementation |
| Rejected | `wontfix` | Will not be actioned |
