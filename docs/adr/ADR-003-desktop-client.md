# ADR-003: 桌面客户端方案

## 状态

已推迟（2026-07-04）

## 背景

Toonflow 使用 Electron 作为桌面客户端，但存在包体大（150MB+）、内存占用高、启动慢等问题。ClipCraft 需要考虑桌面方案。

## 决策

**推迟桌面客户端开发**，优先完成 Web 应用和 API 服务。

### 推迟原因

1. **Tauri**：PoC 测试发现与 Bun/Turborepo 集成复杂，原生模块兼容性问题
2. **Electron**：包体大、内存占用高，与轻量化目标不符
3. **PWA**：功能受限，无法满足本地存储需求
4. **Bun Compile**：需要用户手动打开浏览器，体验不佳

### 未来选项

| 方案 | 适用场景 | 备注 |
|------|----------|------|
| Tauri | 需要轻量桌面应用 | 待 Bun 生态成熟后重新评估 |
| Electron | 需要完整桌面体验 | 原 Toonflow 方案 |
| PWA | 零安装分发 | 适合移动端 |
